# WP-026 — `hod_ir` verification refuses what LLVM's verifier refuses

Landed: `spec/ir.md` §2.1 (module-flag shapes), §5.7 (attribute rules),
§5.8 (the `NotDominated`, `InvalidCall`, `InvalidAttribute` rows, the
definitions of dominance and of `musttail`), §6.8 (debug ids always
checked), §9.8 (what is still left to LLVM, with reasons), §9.9 (the
random printer test without a "parsed only" bucket, `tests/verify_llvm.rs`).

## What it did

| file | contents |
|---|---|
| `src/dom.rs` (new) | `Dominators`: predecessor lists, iterative Lengauer–Tarjan, preorder enter/leave intervals; `reachable`, `dominates` (two compares) |
| `src/verify.rs` | dominance inside the use-facts pass (the tree is built on the first use across blocks or before its definition); `debug_ids` without the "module has debug tables" guard |
| `src/verify/calls.rs` (new) | `call_rules`: `callbr` and `invoke` callees, label constraints, tail markers, `musttail` (`verifyMustTailCall`), `immarg`, bundles |
| `src/verify/attrs.rs` (new) | `signature`: `verifyParameterAttrs` and the position rules, for calls and for function symbols |
| `src/symbol.rs` | `add_function`/`set_function` check the signature's attributes |
| `src/attrs.rs` | `FnAttrs::set` refuses the realtime sanitizer pair |
| `src/props.rs` | `require`/`append`/`append-unique` need a node; `wchar_size`, `SemanticInterposition` an integer |
| `src/intrinsic.rs` | `immediate_args`, `is_invokable` |
| `src/print/body.rs` | `invoke` of `wasm.throw`, `wasm.rethrow`, `fake.use` is not printed for LLVM 19 (it refuses them) |
| `src/error.rs` | `NotDominated`, `InvalidCall`, `InvalidAttribute` |
| `src/random.rs` | the generator builds only what LLVM verifies (dominating operands, constant `immarg`s, valid attributes, debug flags with its tables) |

## LLVM's behaviour, per rule (`llvm-as`/`opt -passes=verify`)

| rule | LLVM 19 | LLVM 22 |
|---|---|---|
| use not dominated; self-use in a reachable block; `invoke` result off its normal edge or over a critical edge | refuses | refuses |
| the same in an unreachable block | accepts | accepts |
| `callbr` of a function | refuses ("only used for asm-goto") | **crashes** (segfault in the verifier): counted as refused |
| `callbr` of asm with another number of `!i` labels; labels on `call` | refuses | refuses |
| `invoke` of a non-invokable intrinsic | refuses | refuses |
| `invoke` of `wasm.throw`, `wasm.rethrow`, `fake.use` | refuses | accepts (so not printed for 19) |
| `tail`/`musttail`/`notail` on `invoke`/`callbr` | parse error | parse error |
| `musttail` conditions (19 cases) | as `verifyMustTailCall` | same |
| `immarg` argument not a constant; `undef`; `poison` | refuses | refuses |
| `kcfi` without exactly one `i32` constant; two of a known bundle | refuses | refuses |
| attribute types and positions (33 call cases, function cases) | refuses | refuses |
| `sanitize_realtime` with `sanitize_realtime_blocking` | — (no such attribute) | refuses |
| `append`/`append-unique`/`require` without a node; `wchar_size` string | refuses | refuses |
| ELF linker option that is not a pair | verifier accepts; `llc` refuses | same |

The linker-option rule is the ELF object writer's (Mach-O and COFF take
any list), so it is not a verifier rule: follow-up for WP-032's
`hod_cg::emit_module`.

## Cost

`examples/body_throughput.rs`, 1,000,001 instructions, release:

| | verify ns/instruction |
|---|---|
| before | 25.8 |
| after, uses within blocks | 26.8 |
| after, a use across blocks in each of 76,924 blocks | 33.3 |

No recursion on body size; one dominator tree per body, built only when
some use needs it; each query is O(1).

## Random printer test (`print/random_tests.rs`, 1500 bodies)

| | verified | parsed only | not printed |
|---|---|---|---|
| LLVM 22 before | 345 | 802 | 353 |
| LLVM 22 after | 1500 | 0 | 0 |
| LLVM 19 before | 324 | 686 | 490 |
| LLVM 19 after | 1299 | 0 | 201 |

LLVM 19's 201 are the four `atomicrmw` operations it lacks (§9.8).

## Fixes outside `hod_ir`

- `hod_interp/tests/instructions.rs`: `unreachable_and_undefined_values`
  built a non-dominated use; it now builds it unverified and asserts that
  `verify` refuses it.
- `hod_interp/tests/robustness.rs`: the wild generator used values
  defined in other blocks without dominance, and non-constant `immarg`
  arguments (`ctlz`/`cttz`/`abs` flag, `memcpy`/`memmove` volatile flag).
- `hod_ll/tests/syntax/rows.rs`: `declare sret(i32) ptr @f()` and
  `declare void @f(ptr elementtype(i32) %a)` are now refused by hod, as
  by LLVM.
