# WP-087 — `-g` modules end to end

Landed: `spec/dwarf.md` §6.12 (and §6.1 families 87, 88; §6.4 refusals;
§9 notes); `crates/hod_ir/src/classify/{matrix,walk}.rs` (debug rows);
`crates/hod/src/back.rs` (the emitter before code generation);
`crates/hod_cg/src/emit/{mod,lines}.rs` (declines by name);
`crates/hod_dwarf/src/{early.rs (new), abbrev, func, inline, types, lib}.rs`;
tests `crates/hod/tests/debug_e2e.rs`, `crates/hod_a64/tests/dies_e2e.rs`
with `data/dies_e2e/e2e.cpp`.

## What landed
- `classify` lets debug modules through on AArch64; `debug:dwarf-version`
  refuses a non-`NoDebug` unit whose `Dwarf Version` is not 5 (absent is
  LLVM's 4).
- The unit plans run before any function is compiled; the DWARF writer's
  input errors are declines (`debug:malformed-metadata`,
  `debug:section-too-large`), not internal errors.
- Whole-unit shapes: retained function-local types (the function's DIE made
  early when the module has its code), unnamed locals (family 87), `alignas`
  locals (family 88), `DIFlagThunk`, template parameters of abstract
  instances (first children), `isUnsignedDIType` of enumerations
  (`static_member_of_unsigned_enumeration` un-ignored).

## Refused by name (new or changed)
`debug:dwarf-version`, `debug:malformed-metadata`, `debug:section-too-large`;
`debug:local-type-scope` (now only a block's type, or a function's without
code here); `debug:variable-alignment` (parameters, unnamed, abstract);
`debug:specification-type` (an abstract instance whose return type differs).
`debug:variable-without-name` is gone.

## Census (130 `-g -O0` modules: 44 libc++ tests, `stl.cpp`, four bench
sources; clang 19, clang 22, kiln++)
First reason of `hod` (strict), `attr:convergent` stripped where WP-086 is
not in this branch:

| reason | modules |
|---|---|
| built | 116 |
| `debug:import-scope` (an import scoped in a lexical block) | 10 |
| `inst:extractvalue/fp128` | 4 |

Before: with the classify rows lifted and nothing else, 40 built,
`debug:local-type-scope` 50, `debug:variable-without-name` 4. Corpus `-g`
modules: 10 of 14 built (2 `debug:dwarf-version`, 2
`intrinsic:llvm.vector.reduce.add`).

Built modules: 116/116 `--verify` clean; 111 link (GNU ld) and run alike;
99 have `llc`'s tree (tags, names, order); line tables equal under §5.7 for
220 236 of 239 416 functions. The 17 tree differences are listed in §6.12
(fallthrough-only inlined calls 6, `llvm.is.constant` dead blocks 8, a type
order 5, overlapping).

`e2e.cpp`: trees equal to `llc`'s for clang 19 (`llc` 19), clang 22 and
kiln++ (`llc` 22); 36 gdb and lldb sessions (breakpoints by line and by
template name, backtrace through an inlined frame, locals, a static member
of an enumeration, a local typedef) equal to `llc`'s under GNU ld, lld and
mold.

## Speed and memory (38 built modules, 5 interleaved runs, medians, load ~17)
hod is 5.9 times faster than `llc -O0` (1.7 to 8.4; 2.9 s against 20.3 s
in all), with 2.9 times less peak RSS (1.7 to 4.1). `.debug_*` is 1.017 times
`llc`'s (0.97 to 1.05), `.debug_info` 1.05 (up to 1.09: two-byte codes).
Decline cost, `stl_heavy.cpp` by clang 22 (9 runs): `classify` decline
100 ms / 28 MiB; plan decline (`debug:import-scope`, all bodies read, no
code) 163 ms / 43 MiB; the same module without debug information, built,
77 ms / 22 MiB.

## Mutations (caught by `dies_e2e.rs`, reverted)
1. `alignment` in bits (`func.rs`): tree differs.
2. no template parameters on abstract instances (`early.rs`): tree differs.
3. every retained local type refused (`early.rs`): `debug:local-type-scope`.
