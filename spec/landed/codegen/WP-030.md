# WP-030 — `hod_cg` core: frames, the location policy, the driver, the test machine

Landed: `spec/codegen.md` §2–§6, §8–§11 for the target-independent core
(§8 now gives the Rust signatures), the crate `crates/hod_cg`, the
test target and its executor under `crates/hod_cg/tests/common/`, and the
`codegen.md` row of `spec/README.md`. Not here: `sym_access` (§7.4) and
`emit_module` (§9.7), which are WP-032, and every real target.

## What it did

- `src/`: one module per spec section group (the table is in `lib.rs`):
  `target` (the `Target` trait), `cx` (`FnCx`, `Scratch`), `policy` (the
  location policy v1, §4.1–§4.4, §4.6), `phi` (§4.5), `call` (§7.1–§7.3,
  `musttail`, `invoke`), `driver` (`compile_function`: reachability, the
  block walk, entry code, far-mode retry, truncation on error), `frame`,
  `label`, `record` (`Chunk`, `FuncRecord`, rows), and the supporting
  `abi`, `loc`, `reg`, `sym`, `error`, `options`.
- `tests/common/`: the test machine ("TM", `isa.rs`): a byte-coded
  register machine with 12 general and 8 float registers and a pool of 5
  and 4, so displacement is constant; `target.rs`, `Tm: Target`, written
  as a real target is meant to be (deferral and fusion of compares and
  constant `ptradd`s, calls through `FnCx::call`, `mem*`, `frem` and
  128-bit division as runtime calls); `exec.rs`, an executor that is
  strict where hardware is forgiving (a call poisons every non-argument
  register, a narrow result leaves ones above its width, the stack starts
  as `0xAA`, a `ret` checks the stack, frame and argument pointers, and
  narrow arguments are checked for extension); `harness.rs`, the
  differential harness against `hod_interp`.
- `tests/policy_diff.rs`: generated programs (`hod_interp::generate`, 29
  option sets) compiled under the five stress modes (plain, min-pool,
  far, displace, all) and run; the result and the trace of host calls
  must equal the interpreter's. Quick batch: 4 seeds per option set; the
  `#[ignore]`d `long_batch` takes `HOD_CG_SEEDS`.
- `tests/policy_cases.rs`: the §12 cases, one named test each (below).
- `tests/throughput.rs`: an `#[ignore]`d measurement.

The test target lives under `tests/` so that no build of the library
contains it; it is the only target until WP-033, and the oracle for its
runs is `hod_interp`, never `llc`.

## Evidence

- `cargo test -p hod_cg`: 11 unit tests, the quick differential batch
  (116 programs, 580 compiled runs, all equal), 13 policy cases.
- Long batch, `HOD_CG_SEEDS=2000` (seeds `1000 + k·1000003 + 0..2000` for
  option set `k`): 58000 programs, 290000 compiled runs, all equal to the
  interpreter; none rejected by the core or the target, none unsupported
  by the interpreter; 121.0 M IR instructions, 1.82 G machine steps,
  41.4 M host calls compared; 1330890 function attempts, of which 670890
  in far mode (the TM's near branches reach ±1 KiB on purpose).
- The long batch found one bug, in the test target: a lowering asked
  for its other operands before a deferred one, and under min-pool ran
  out of registers (`no-globals`, seed 14001094, an `Internal` error,
  not wrong code). Fixed by `deferred_first` in `tests/common/target.rs`,
  which makes the obligation of §8.1 hold for every lowering; the case is
  `deferred_operand_that_is_not_the_first`, which fails without the fix.
- Hand mutations, each reverted; every one fails the quick differential
  batch:

  | mutation | differential batch | policy cases failing |
  |---|---|---|
  | no displacement before a call | first program (`default`, seed 1) | 4 |
  | a value used in another block kept in its register across the label, end-of-block check removed | second program (`default`, seed 2); with the check kept, `Internal` at seed 1 | 0 |
  | `phi` incoming slot = the `phi`'s home (copies without the cycle break) | 13th program (`sized-2x200`, seed 3000010) | `phi_swap`, `phi_self_loop` |
  | a pinned temporary handed out again as a temporary | first program | 9 |
  | no store to the home in `finish` | first program | 4 |

- Throughput (`cargo test -p hod_cg --release --test throughput --
  --ignored --nocapture`, one thread, TM): 132969 IR instructions in
  34.1 ms, 3.9 M IR instructions/s, 76 MB/s of code. The TM's encoding is
  not a real one; the figure is a baseline for the core's own cost.

## The §12 cases

`dead_instruction_with_register_operands`,
`dead_instruction_with_deferred_operand` (§4.2); `phi_swap`,
`phi_self_loop` (§4.5); `far_branch_retry_leaves_no_trace` (§6.3, §10:
the retried function's rows equal far mode from the start, the function
before it is untouched); `unreachable_blocks` (§6.1, one a `phi`'s
predecessor, one its own); `address_taken_blocks` (§6.1, §9.6: one block
no `indirectbr` lists, bound to the shared trap; the interpreter does not
run `blockaddress`, so these results are by hand);
`musttail_swapping_stack_arguments` (§7.1); `values_held_across_a_call`
(§4.4); `determinism_alone_and_among_others` (§11);
`an_error_leaves_the_chunk_as_it_was` (§1, §10: `limit:frame-size` from
the core and from the target, `limit:function-size` from a failed far
retry); `over_aligned_slot` (§5.1); `deferred_operand_that_is_not_the_first`
(§4.6, §8.1).

## Deviations from the design, now in `spec/codegen.md`

1. `FrameRef::Outgoing(u32)`: stack arguments are addressed from the
   lowered stack pointer (§5.3).
2. Glue beyond the original §8.2: `materialize_mem`, `frame_addr`,
   `copy_from_ptr`, `adjust_sp`, `extend_arg`, `jump`, `emit_call`,
   `dynamic_slot`: the generic call sequence and driver need them.
3. `type FnState: Default`, held in `FnCx::state`; `Scratch` is not
   generic, so one serves any target.
4. `RegInfo` has `callee`, `gpr_bytes`, `fpr_bytes`; `dwarf` is a function.
5. The driver, not `begin_function`, emits argument entry code (§4.8) and
   lays out body slots; over-aligned slots go through `dynamic_slot`.
6. `TRAP` is a byte slice.
7. A `filter_ids` table in `Chunk` (§9.4).
8. Branch out of range is an internal flag; `CgError` keeps its two
   variants.
9. The driver adds the epilogue's line row before `end_function`; only
   instructions that emitted code get rows; `phi` loads count as the
   block's first emitting instruction's.
10. The driver does a terminator's `phi` stores before lowering it (an
    `invoke`'s are the call sequence's); calls emit deferred arguments
    first; a deferral run is at most `MAX_DEFERRED_RUN = 8`; a lowering
    asks for a possibly-deferred operand before pinning others.
11. After a `returns_twice` call no spill slot is reused at all.
12. `block_offsets` only for functions with an `IndirectBr` (`hod_ir`
    has no address-taken marker; open question in §13); all unreachable
    blocks share one trap.
13. A `Mem`-class result with no use is dead; `def_mem` gives it a slot
    for the instruction.
14. A direct call's missing call-site attributes come from the callee's
    declaration (open question in §13).
15. A call-site row covers everything `emit_call` emits; rows only in
    functions with landing pads; pad and landing resolved at function
    end, `landing == 0` meaning the pad block's offset.
16. Named `call:` reasons (§10).
17. `tail_exit_count()` / `tail_exit(i)` instead of a slice; `CallArg`
    has no immediate variant.
18. A stack argument wholly in one stack part has home `Incoming(offset)`
    and the part's width.
19. `place_return` leaves `ret_memory` returns to the target.
20. `MAX_FUNCTION_SIZE` is 1 GiB; a chunk holds less than 2 GiB of code.

## Not covered

- `invoke`, landing pads and `resume` have never run: `hod_interp` does
  not run them and its generator does not produce them, though the
  executor can unwind through a chunk's tables. The core's `invoke` path
  is written to §7.1 but unverified; it needs an oracle (an interpreter
  extension) before a real target relies on it.
- A value held across a `returns_twice` call with a later `longjmp`
  (§4.3), an `invoke` with stack arguments caught a million times (§5.3),
  an interposed function with a `blockaddress` table (§9.6): need
  `setjmp`/`longjmp` in the executor, EH in the oracle, and WP-032.
- `#dbg_declare` of a non-slot, `#dbg_label`, `#dbg_value` (WP-005).
