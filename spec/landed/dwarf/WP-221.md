# WP-221 — two differences real runs found

The contract is `spec/dwarf.md` §6.30 (with §6.4, §6.7, §6.17, §6.23 and
`spec/codegen.md` §4.1, §9.5). This file records what the package found
and did.

## Part A: the recorded command line

- A `DICompileUnit`'s `flags:` (`-grecord-command-line`,
  `-grecord-gcc-switches`) is appended to `DW_AT_producer` after one
  space, as `llc` 19 and 22 write it: in the ordinary unit (DWARF 5 and
  4), the split unit and a skeleton that stands alone.
  `crates/hod_dwarf/src/producer.rs`, `UnitPlan::producer`.
- Modules without flags write the bytes they wrote before.
- `crates/hod/tests/kiln_forwarded_options.rs` on WP-214's branch carries
  an `#[ignore]` for this; it can be lifted once WP-214 and WP-221 are
  both on main.

## Part B: a declaration of an instruction result

What `llc` does (19.1.7 and 22.1.8, both targets, clang 19's and 22's
ramps, kiln++'s saved `fullexpr-dtor.pass.cpp` ramp at kiln++
21b9110a4, hand IR):

- SelectionDAG (the reference): a `phi`'s declaration is dropped (a
  retained `__coro_frame` keeps a DIE without a location, the others get
  none); a `getelementptr` of the block gets a register-only list.
- FastISel / GlobalISel (llc's default `-O0`): a list from the
  definition, register first, then the spill slot dereferenced; a
  variable declared on a slot as well keeps the slot.

What hod does now: a list `DW_OP_fbreg o, DW_OP_deref, E` over the
blocks the definition dominates, from the end of the definition's code
(a `phi`: of its block's `phi` loads), each range ending at its block's
end or a non-branch terminator. Never computed (dead) results get no
range and then no DIE. A slot plus a constant offset stays refused
(`debug:declare-offset`, or `debug:declare-address` when never
computed). Arguments keep `FrameIndirect`. Coroutine bodies hod lowers
are unchanged.

- DWARF 4: `.debug_loc` (`crates/hod_dwarf/src/dwarf4.rs` `loc_list`);
  the location-list families are now checked for version 4, so §6.23's
  `#dbg_value` lists are written there too (the refusal
  `debug:dwarf-4-shape` for them is gone).
- Split: `.debug_loclists.dwo`, as §6.23.
- A dynamic `alloca` (a variable-length array) is an instruction result
  too: hod now writes a list where it wrote `DW_OP_fbreg o, DW_OP_deref`,
  as `llc` does, and the `sret` class no longer covers it.
- Fixed on the way: a dead result named only by a declaration was
  described for the whole function by a home never written.
- `cargo xtask debug trees`: the class `declared value` (§6.7), by the
  names of the variables the module declares on a `phi`; the surplus
  `.debug_loclists`/`.debug_loc` and (DWARF 4) `.debug_str` relocations
  of those DIEs; the `sret` class now drops only `llc`'s lists beyond
  hod's.
- No abbreviation family was added.
