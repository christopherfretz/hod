# WP-149 — key instructions

The contract of what landed is `spec/dwarf.md` §5.9 (with the x86-64
fused-compare paragraph of §5.8), `spec/ll.md` §11.9, `spec/bc.md` and
`spec/ir.md` §6.5 (atoms). This file records what the work package did,
what it measured, and what it left.

## What the front ends emit

- clang 22 at `-O0`: no key-instruction fields. At `-O1`, `-O1 -Xclang
  -disable-llvm-passes` and `-O2`: `DISubprogram(keyInstructions:
  true)` and `DILocation(atomGroup:, atomRank:)`. `-gkey-instructions`
  forces them at `-O0`; clang 19 rejects the flag.
- kiln++: none, and it rejects `-gkey-instructions`. No module of the
  corpus has the fields.

## What landed

**a. The readers** (`hod_ll`, `hod_bc`) keep `keyInstructions` and each
location's atom (`hod_ir::DiAtom`, part of the location's identity);
the printer writes them back. Before, both were dropped.

**b. The rows** (`crates/hod_cg/src/key_rows.rs`): in a function with
key instructions every segment that emitted code is a row; a row whose
code ends with a call is marked (`ROW_CALL`) and the code after the call
is a row of its own; tail-exit rows and an epilogue row whose `ret` is
not in the last block are continuations (`ROW_CONT`). `decide` chooses
the key rows by K1 to K6; `hod_dwarf::Stmt` (`Line`, `Key`, `NotKey`)
carries the choice to the policy. Refusals (K7):
`debug:key-instructions-mixed`, `debug:key-instructions-coroutine`.

**c. x86-64**: a compare fused into its branch keeps the `icmp`'s
location (`crates/hod_x64/src/control.rs` `cond_br`), as `llc` does;
§5.8's columns same-set rose 666 → 732 of 981 functions at `-O0`.

**d. The harness** (`xtask/src/debug/`): the permitted class
`prologue-end`, read from the IR's `keyInstructions`; `columns` counts
functions whose `is_stmt` sequence equals `llc`'s.

**e. Tests**: `tests/debug/key_multiline.c`, `key_loop.c`,
`key_inlined.c` (clang 22 only), `key_call.c` (`xfail(x86_64, gdb)`:
`llc`'s session shows the parameter before its spill, with clang 19
too); `call_sites.c` no longer xfail for clang 22's gdb;
`crates/hod_dwarf/tests/key_stmt.rs`; `key_rows` unit tests.

## Cost

Instructions (callgrind, one thread, a 9.2 MB `-O0` module and the same
at `-O1 -disable-llvm-passes`, 9.7 MB), base 3a98566 against WP-149:

| input | base | WP-149 |
|---|---|---|
| plain `.ll` | 742.97 M | 746.29 M (+0.45 %) |
| atoms `.ll` | 770.80 M | 777.64 M (+0.89 %) |
| plain `.bc` | 578.92 M | 582.63 M (+0.64 %) |
| atoms `.bc` | 584.10 M | 598.64 M (+2.5 %) |

Of the atoms runs, `decide` and `candidate` are 2.3 M. Wall times are
within the host's noise (±10 %). Line-row emission
(`hod_dwarf/tests/throughput.rs`, 2 M rows): policy 7.6 → 7.4 ns/row,
writer 13.5 → 13.8 ns/row, the same bytes.

## Mutations (each caught, then reverted)

1. An equal rank clears the candidates (`candidate`, `>` to `>=`):
   `key_rows::tests::ranks_and_blocks` fails.
2. A call with an atom becomes a candidate (`decide`, K4):
   `key_rows::tests::a_call_of_a_better_rank_and_continuations` fails.
3. `NotKey` sets `is_stmt` on a change of line (`policy.rs`):
   `key_stmt::key_and_not_key_rows` fails.
