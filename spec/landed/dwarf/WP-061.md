# WP-061 — reduced units and compressed debug sections

The contract of what landed is `spec/dwarf.md` §6.9 (reduced units), §1.1
and §9 (compressed sections in the bridge), `spec/object.md` "Compressed
sections" (the writer and the compressor) and `spec/cli.md` "hod's own
options". This file records what the work package did, what it
measured, and what it left.

## What landed

**A. `LineTablesOnly`, `DebugDirectivesOnly`, mixed modules.**

- `crates/hod_dwarf/src/reduced.rs` (new): `check_unit`, `add_function`,
  `has_dies` and the three refusals below. Hooks: `die.rs:224`
  (`UnitPlan::build`, where `debug:emission-kind`-style refusal was) and
  `func.rs:298` (`UnitPlan::add_function`).
- `crates/hod_cg/src/emit/lines.rs`: every unit but `NoDebug` gets a plan
  (`:118`); `Unit::dies` (`:124`) keeps `DebugDirectivesOnly` units out of
  `write_debug_info` (`:330`); a module of only such units writes no
  `.debug_info`. `debug:emission-kind` is gone (`emit/mod.rs`).
- DIE trees, per kind, equal to `llc` 19 and 22's: `FullDebug` as before;
  `LineTablesOnly` the unit DIE alone (no subprogram for a function
  without inlined code); `DebugDirectivesOnly` no `.debug_info` at all,
  `.debug_line` and `.debug_line_str` only; `NoDebug` nothing. The line
  table of a reduced unit is byte-equal to the `-g` one.

Refused by name (`pub const` in `hod_dwarf`): `debug:line-tables-inlined`
(a `LineTablesOnly` function with inlined code: needs WP-085's inlined
subroutines), `debug:line-tables-variables` (variable or label records
under `LineTablesOnly`), `debug:reduced-unit-entities` (a reduced unit
listing globals, enums, retained types or imports).

**B. Compressed sections.**

- `crates/hod_obj/src/deflate.rs` (new, public module): the zlib
  compressor. Greedy LZ77, one candidate per position from a 2^15-entry
  `u32` hash table of four bytes, no chains, 8-byte match extension,
  skip-ahead after 32 misses; 256 KiB independent segments, each one
  block of the cheapest kind by exact bit count (dynamic, fixed,
  stored), padded to a byte; empty final fixed block; Adler-32
  big-endian. No dependency, no `unsafe`.
- `crates/hod_obj/src/compress.rs` (new): `Compression`,
  `Object::compress_section`, `Object::compress_debug_sections`
  (`Elf64_Chdr`, `SHF_COMPRESSED`, alignment 8, unchanged when it does
  not shrink); `Error::NotCompressible`, `Limit::CompressedBytes`
  (appended under a WP-061 comment, `error.rs`); the writer's relocation
  bound uses `ch_size` (`elf.rs:465`).
- Options: `hod_cg::Options::debug_compression` (`options.rs:20`),
  applied last in `ModuleEmitter::finish` (`emit/mod.rs:862`; a section of
  4 GiB or more is `limit:compressed-section`); `hod::Options::
  debug_compression` (`hod/src/lib.rs`, `back.rs` `cg_options`); `hod
  --compress-debug-sections=<none|zlib>` and
  `HOD_COMPRESS_DEBUG_SECTIONS` (`hod_cli/src/args.rs`, `driver.rs:40`);
  `zstd` refused by name. `crates/hod_a64/tests/control.rs` gains the
  field in its `Options` literal.

## Evidence

- `crates/hod_a64/tests/reduced.rs`: trees and sections against `llc` 19
  and 22 on clang 19, clang 22 and kiln++ IR, `--verify` clean on both:
  `LineTablesOnly` 8 objects (4 units), `DebugDirectivesOnly` 16, mixed
  modules (full, line-tables, directives, `-g0`, five link orders) 20
  objects, 14 units, 38 DIEs; the refusals by name.
- `crates/hod_a64/tests/reduced_debugger.rs`: gdb and lldb on the
  line-tables program and the mixed program, GNU ld, lld and mold, LLVM
  19 and 22: 24 + 24 sessions equal to `llc`'s.
- Corpus: no `LineTablesOnly` or `DebugDirectivesOnly` module (14
  `FullDebug`). `stl.cpp` with `-gline-tables-only` (clang 19, 22, kiln:
  385 functions, 210 `inlinedAt` locations): before, the whole module was
  `debug:emission-kind`; after, 34 of 385 functions are
  `debug:line-tables-inlined` (`llc` writes 34 concrete subprograms, 59
  inlined subroutines for them), and the first refusal of the module is a
  code generator one (`a64:atomic`).
- `crates/hod_obj/tests/deflate.rs`: 3 000 generated inputs (empty, 1
  byte, incompressible, runs, periods, text, sparse, past 64 KiB and past
  segments, 65 535 ± 1) decoded by Python's `zlib.decompressobj` (exact
  end, no trailing bytes, Adler-32); size bound; determinism across a
  fresh, a reused and the free compressor.
- `crates/hod_a64/tests/compressed.rs`: a `-g` C++ program, the
  line-tables program and a generated 6 000-function C program (seven
  sections past 64 KiB, two past 256 KiB; 1.09 MB into 133 KB), each from
  clang 19 and 22: the compressed object is the plain one but for the
  compressed sections (headers checked; Python `zlib` and `llvm-objcopy
  --decompress-debug-sections` give the plain bytes back);
  `llvm-dwarfdump --verify` 19 and 22 clean; `llvm-dwarfdump --all` and
  GNU `readelf --debug-dump` print the same as for the plain object with
  an empty error stream; gdb on the object equal; lldb on the object
  equal to lldb on LLVM's compression of the same object (below); linked
  with GNU ld, lld and mold the programs run, their DWARF reads the same
  as the plain programs' and gdb and lldb sessions are equal (32 + 32
  sessions): the relocations against compressed sections applied.
- Speed and ratio (`tests/deflate_throughput.rs`, ignored; clang 22 `-g`
  objects of `stl.cpp` and a heavier standard-library TU, 1.8 MB of
  `.debug_*`): hod 306 MB/s, ratio 4.83; zlib -1 199 MB/s, 4.85; LLVM
  `-gz=zlib` 5.54. Memory: 128 KiB table + 1 MiB tokens per compressor.

Mutations, each made, run and reverted: (A) `has_dies` true for
`DebugDirectivesOnly` (the directives and mixed tests); full DIEs under
`LineTablesOnly` (the line-tables, mixed and refusal tests); the inlined
refusal disabled (`refusals_by_name`). (B) Adler-32 off by one bit
("incorrect data check"), the segment block's BFINAL set (the stream
ends early: Adler mismatch at input 4), distance 2 sent as distance code
0 (input 10 decodes wrong) — all caught by
`python_zlib_decodes_every_stream`.

## Found elsewhere

- lldb 19 reads no DWARF from a relocatable object whose debug sections
  are compressed, `clang -gz=zlib`'s included (`type lookup` finds
  nothing); linked programs are fine. Not hod's.
- `llc` 22 crashes on a `LineTablesOnly` unit with globals or variable
  records, and writes a stray `.debug_addr` for a `DebugDirectivesOnly`
  unit with globals (hence the refusals).

## Left for later

- `debug:line-tables-inlined` goes when WP-085's inlined subroutines
  land: the subprogram (`low_pc`, `high_pc`, `name`), abstract
  subprograms and `inlined_subroutine` children, `reduced.rs`
  `add_function`.
- `classify`'s `debug:*` rows (`crates/hod_ir/src/classify/walk.rs`)
  still refuse every debug module, so neither reduced units nor
  compression reach the command line yet; modules without `FullDebug`
  units could be let through first.
- `debugInfoForProfiling` (`spec/dwarf.md` §11 question 10).
- Compression is serial; segments are independent, so a parallel
  compressor needs no format change. zstd is not written.
