# WP-035 — the AArch64 integer group

Landed: `crates/hod_a64/src/int.rs`; `spec/codegen.md` §5.5.1
"Integers (WP-035)"; the support-matrix rows of the group; the
differential harness's generator switched on.

## What is lowered

On `Gpr` values of every width, `i1` to `i64` (the odd widths
included), and pointers where the IR allows them:

- `add`, `sub`, `mul`, `udiv`, `sdiv`, `urem`, `srem`, `and`, `or`,
  `xor`, `shl`, `lshr`, `ashr`, register or constant on either side;
- `icmp` with every predicate, on integers and pointers: deferred when
  the policy allows, fused into `select` (`csel`), `zext` (`cset`) and
  `sext` (`csetm`); `int::fusable` and `int::flags` are the contract for
  other consumers (§5.5.1);
- `trunc`, `zext`, `sext`, `ptrtoint`, `ptrtoaddr`, `inttoptr`,
  `bitcast` between `Gpr` types;
- `select` (condition fused or `tst #1`; a 0 arm is `xzr`), `freeze`.

## Refused, by name

- `a64:addrspacecast` (`int::ADDRSPACECAST`): `addrspacecast` (classify
  rejects its non-zero address spaces first).
- `a64:int-binary`, `a64:int-cast`, `a64:icmp`, `a64:int-select`,
  `a64:int-freeze`: only for forms the dispatch should never send (a
  non-integer opcode); `i128` and other `Mem` values go to `aggr`
  (WP-040, `a64:mem-*`).

## Evidence

- `tests/int.rs` with `tests/common/int_gen.rs`: every case runs under
  `hod_interp`, natively from one C driver with hod (plain and
  `Stress::ALL`) and with `llc -O0 -global-isel=0 -fast-isel=0`;
  arguments carry random bits above their width.
  - binary table (every operation x 17 widths, register/constant
    operands, edge values): 41,879 cases compared;
  - compares and selects (every predicate x widths and pointers, value
    and fused forms, `freeze`): 142,220;
  - casts (every pair of widths, pointer casts): 7,982;
  - 1,500 random straight-line functions (with `br`s): 5,685 cases.
  Cases the interpreter traps on (undefined in LLVM) run but are not
  compared. `freeze poison` is not compared with `llc` (arbitrary).
- Exact words of the short forms and of the fusions.
- `tests/diff.rs`: 200 generated programs agree with the generator
  options of this package (100% ran end to end); with the default
  options every program is skipped by another group's name (counted by
  name, never as agreeing).
- Mutations caught (each reverted): `sdiv` operands zero-extended
  instead of sign-extended; the `lsl` before an odd-width register
  compare dropped; the shift amount of widths below 5 not masked.

## Measurements (debug build)

- About 1.1 µs per IR instruction for the random functions (2.7 to
  3.2 µs in the one-instruction table, which the prologue dominates).
- Code: hod 10.0 bytes per IR instruction against `llc`'s 3.76 on the
  random functions (18.4 against 6.4 on the binary table; `llc -O0`
  omits the frame of a leaf).
