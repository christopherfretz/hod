# WP-072 — constant operands with addresses

Landed: `crates/hod_a64/src/constaddr.rs` (new), two one-call hooks in
`crates/hod_a64/src/common.rs` (the `SymDiff` arm of
`materialize_gpr_const`; the non-plain image arm of
`materialize_mem_const`), the module line in `crates/hod_a64/src/lib.rs`,
`crates/hod_a64/tests/constaddr.rs`, `tests/ir/const_operands.ll`, the
heading "Constant operands with addresses (WP-072)" in `spec/codegen.md`
§5.5.1, and the support-matrix rows `operand:int-of-addr`,
`operand:sym-diff`, `operand:address-in-aggregate` (on for AArch64).

## What is lowered

Every address is computed in code (`sym_address`, `block_address`) and
stored or kept in the register: no constant pool, no data relocation.

| form | class | how |
|---|---|---|
| `IntOfAddr` (`ptrtoint` of an address, any width up to 64, truncated or not) | `Gpr` | the address in the register (existing `materialize_gpr_const`; high bits unspecified) |
| `SymDiff` (`a - b + addend`, any width up to 64) | `Gpr` | `a + addend` in rd, `b` in the other scratch, `sub` |
| aggregate with aligned 8-byte symbol addresses only | `Mem` | `common::write_image` (WP-040's path, now reachable) |
| aggregate with any other relocation: 1/2/4-byte fields (truncated addresses), unaligned fields (packed structs), block addresses, `dso_local_equivalent`, differences, at any frame offset | `Mem` | `constaddr::write_image`: data runs as 8/4/2/1-byte stores, each field computed in `x17` and stored with its width |

In every operand position: `store`, `insertvalue`, `select`, `icmp`,
arithmetic, `phi` (scalars), call arguments (by value aggregates
included), `ret`.

## What is refused, by name

- `a64:constant`: an `i128` or wider `ptrtoint` of an address, and an
  address in an image integer whose width is not 8/16/32/64 (no image,
  `spec/ir.md` §4.3).
- `a64:constant-relocation`: a vector constant whose image has a
  relocation other than an aligned 8-byte symbol address (vectors are
  not this package's).
- `tls:address-in-constant` (classify): a thread-local symbol in any of
  these forms (WP-073).
- `operand:dso-local-equivalent`, `operand:no-cfi`: those as scalar
  operands, unchanged.
- `const-expr:<op>`: every `Expr` `hod_ir` keeps (a number minus an
  address, a difference of block addresses, ...).

## Evidence

- `tests/constaddr.rs`: 56 self-checking functions (each returns 0 when
  every field read back equals the address computed by instructions from
  a pointer reloaded through a `volatile` slot) over 9 symbols (internal,
  default, `dso_local`, defined in C, hidden, `extern_weak` undefined,
  internal/default/C functions) × offsets 0, 24, -8, 4099, plus block
  addresses jumped through and `dso_local_equivalent` called through;
  the C driver also checks the addresses against gcc's own. Built by hod,
  hod under `Stress::ALL` and `llc -O0 -global-isel=0 -fast-isel=0`;
  static code linked non-PIE, PIC code linked as PIE and as a shared
  library; bfd, lld, mold: 27 programs, all `0 failed`. 30 cases (the
  module's own symbols, differences as addresses) also return 0 under
  `hod_interp`. Classify accepts the whole module with the shipped matrix.
- `tests/ir/const_operands.ll` (clang++ 22 `-O0`: member-function
  pointers called through, a function table filled in code, a function
  minus a variable, 32- and 16-bit truncated addresses): `cargo xtask
  irdiff --witness` 3 PASS (bfd, lld, mold). The same source through
  kiln++ 22 and hod (PIC) prints the same lines.
- Corpus: see "Corpus" below.

## Mutations (each caught by `the_cases_run_under_every_linker`, reverted)

1. The addend of a symbol field dropped in `constaddr::write_image`.
2. The operands of the difference's `sub` swapped.
3. A 4-byte field stored as 2 bytes.

## Bugs found elsewhere

- `hod_ll` does not read an aggregate constant as a `phi` incoming value
  (`crates/hod_ll/src/index.rs:463`): `#[ignore]`d test
  `hod_ll_reads_an_aggregate_phi` in `tests/constaddr.rs`.

## Corpus

Census (`cargo xtask corpus reasons`, this branch): `(compiled)` 3120
(LLVM 22) and 3086 (LLVM 19) of 3347 / 3308; `operand:int-of-addr`,
`operand:address-in-aggregate` and `operand:sym-diff` are gone from the
first refusals and from the census. Of the modules main's hod refuses by
these reasons (52 per major: 31 `address-in-aggregate`, 21
`int-of-addr`), 50 per major compile now; the other 2 per major stop at
`type:vector` (a `<1 x i64>` holding a `ptrtoint`). `cargo xtask corpus
verify --strict -j 4` over the 100 newly compiling modules (a sub-corpus
with the filtered manifest): LLVM 22 150 PASS, LLVM 19 150 PASS (bfd,
lld, mold), 0 FAIL.
