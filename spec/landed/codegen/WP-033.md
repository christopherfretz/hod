# WP-033 — the AArch64 target skeleton

Landed: `spec/codegen.md` §5.5.1 (the decisions the group packages build
on), `cfi_at` in §8.1, the `fp128` note in §7.5, two open questions in
§13; crate `hod_a64` laid out for WP-035..041; the support-matrix rows
of what is implemented and tested.

## What it did

- `hod_a64::A64` implements `hod_cg::Target`: register description,
  classes, the final dispatch (`src/target.rs`), the glue (loads, stores,
  copies, moves, constants, frame addresses), the frame (`src/frame.rs`:
  prologue, exit sequences and tail exits, CFI rows, incoming base,
  dynamic slots, the call instruction), `br`, `ret`, `unreachable`
  (`src/term.rs`), shared helpers (`src/common.rs`).
- One stub module per group (`int`, `mem`, `control`, `call`, `float`,
  `aggr`, `intrinsic`), each refusing with stable names; the ownership
  table is the crate documentation (`src/lib.rs`).
- `hod_a64::compile_module` (module and bodies to `hod_cg::Emitted`) and
  `compile_to_object` (to ELF bytes).
- `hod_cg`: one missing hook, `FnCx::cfi_at` (rows at an offset already
  emitted, in order), so that the prologue's rows can be added when the
  frame size is known. Tested by `hod_a64/tests/frame.rs`.
- Rows flipped on AArch64: `module:pic`, `module:pie`,
  `global:function-definition`, `function:parameters` (every class; the
  `type:*` rows still gate), `cc:ccc`, `attr:target-cpu`, `type:int`,
  `type:ptr`, `inst:br`, `inst:ret`, `inst:unreachable`,
  `operand:symbol`, `operand:addr-of-int`. `attr:target-features` stays
  (§13).

## Tests

- `tests/skeleton.rs`: the builder-made `main` returning 42, linked by
  GNU ld, lld and mold and run; the exact words of the smallest function;
  classes; a refused group leaves no trace; ns per trivial function.
- `tests/frame.rs`: prologue and epilogue words, CFI rows and
  `llvm-objdump` text for frames of 16, 32, 4080, 4096, 4112 and
  2^24 - 16 bytes; one step more is `limit:frame-size`; the incoming
  base; a dynamic slot.
- `tests/native.rs`: an `.ll` module of 42 functions (returns of every
  register class and in memory, stack, FP, HFA, `i128` and vector
  arguments, every symbol access kind) called from C and checked under
  every linker; the symbol functions' relocations equal `llc`'s
  (`-O0 -global-isel=0 -fast-isel=0`) static, PIC and PIE.
- `tests/{int,mem,control,call,float,aggr,intrinsic}.rs`: each stub's
  reasons.
- `tests/diff.rs`: the differential harness (§5.5.1); 200 programs in
  the default run, 1000 in `many_programs_agree`; the mutation check
  (a wrong constant and a wrong branch target are reported for exactly
  those programs, in plain and stressed mode).

## Results

- 221 ns per trivial function (release, warm worker); 2.6 µs in debug.
- The harness: 0.66 s per 1000 programs (release; 500 per batch, two
  modes: interpreter, printing, parsing, two compilations, links and
  runs).
- No encoding was missing from `hod_mc_a64`.
