# WP-037 — AArch64 control flow

Landed: `spec/codegen.md` §5.5.1 "Control flow (WP-037)"; `hod_a64`'s
`control` module, `common::block_address`; the support-matrix rows of
what is implemented and tested.

## What it did

- `condbr`: `tbz`/`tbnz` of bit 0 with the branch to the next block
  omitted; a constant condition or two equal targets are a `br`. Correct
  whatever the condition is (an argument with junk above bit 0, a `phi`,
  a constant, a deferred value, which is emitted first). The fusion of a
  deferred `icmp`/`fcmp` is left to the integration package after WP-035
  and WP-039: one marked place in `control::cond_br`.
- `switch` on every `Gpr` width, `i1` and odd widths included: zero
  extension in place, cases to the default dropped, unsigned sort,
  binary search with linear runs of at most `LINEAR_CASES` (4). Linear
  code, `log2(n) + 4` compares per run, `n log n` compile time only for
  cases that do not come sorted; 5000 cases compile in about 16 ms
  (debug build). No jump table: none is needed for the "nothing worse
  than linear" rule, and none means no relocation against the function's
  own code (§6.2), which keeps `function_sections` and COMDAT trivial.
- `indirectbr`: `br` of the register; a `blockaddress` operand in `x16`.
- `common::block_address` (added at the end of `common.rs`): `adr` with
  fixup kind 4; in far mode a five-instruction sequence that reads the
  distance from a never-executed `b label` (its 26-bit field reaches the
  whole function).
- `phi`: nothing in the target (§4.5); tested on the target.

## Refused

| name | what | why |
|---|---|---|
| `a64:switch-wide` | `switch` on an integer wider than 64 bits | `Mem` class; `classify` rejects it first (`inst:switch` is `int` only) |
| `a64:blockaddress` | a `blockaddress` the glue materializes: as a `phi`'s incoming value, a call argument, a stored value | `common.rs:557` (`materialize_gpr_const`) refuses it; the change is one line, below |

`COND_BR`, `SWITCH`, `INDIRECT_BR` remain as names but are no longer
returned.

## Needed elsewhere

- `crates/hod_a64/src/common.rs:557`: replace
  `Const::BlockAddr { .. } => return unsupported(BLOCKADDRESS),` by
  `Const::BlockAddr { func, block } => block_address(cx, rd, func, block)?,`.
  With it applied locally, `graphs_with_block_address_phis_agree` (1200
  graphs whose `indirectbr`s go through `phi`s of `blockaddress`es, in
  plain, stressed and far mode) passes; then un-ignore that test, delete
  `a_block_address_the_glue_materializes_is_refused_by_name`, and flip
  `operand:blockaddress`.
- `hod_ir` (BACKLOG WP-064): `Phi::value_for(block)` would not have
  changed this package (the driver reads `phi`s, not the target). An
  address-taken marker on blocks would let `block_offsets` be recorded
  for a function without an `indirectbr` (§9.6, §13): today a
  `blockaddress` in data of such a function is `init:blockaddress-unplaced`
  in `hod_cg`, so `init:blockaddress` is supported only for functions
  with an `indirectbr`.

## Matrix rows flipped (AArch64)

`inst:condbr`, `inst:indirectbr`, `inst:phi` (every class: the `type:*`
rows gate the classes; `int` and `ptr` are tested here, `phi`s of the
other classes ride on WP-033's glue and are WP-039's and WP-040's to
test), `inst:switch` (`int` only), `init:blockaddress`,
`attr:no-jump-tables`. `operand:blockaddress` stays (above).

`inst:phi` is `ON` rather than `on(int, ptr)` because a class-restricted
row makes `classify`'s census and its verdict disagree: the verdict
reports `inst:phi/double` where the census lists only `type:double`
(`crates/hod_ir/tests/classify_random.rs:850`,
`tame_programs_are_decided_consistently`, seed 2). A bug in
`hod_ir::classify` for whichever package next restricts a row by class.

## Tests (`crates/hod_a64/tests/control.rs`, generator `tests/common/control.rs`)

The oracle is `hod_interp`; each batch is one module, one object per
mode (plain; `Stress::ALL`; far mode alone), one C driver that calls
through a six-argument pointer with random bits above every argument's
width (above bit 7 for `i1`), one process per mode.

- `random_graphs_agree_with_the_interpreter_and_llc`: 1800 random
  control-flow graphs (DAGs of `br`, `condbr`, `switch`, `indirectbr` on
  a `blockaddress`, `ret`, with header loops whose rotation `phi`s read
  each other on the back edges and self loops with swapping pairs;
  `phi`s of `i1`..`i64`, odd widths and `ptr`, incoming constants,
  `undef`, `poison`, other `phi`s, a block listed several times by one
  predecessor; shuffled layout), six argument sets each: 10,800 calls x
  3 modes; 600 of the graphs (no `undef`) also through
  `llc -O0 -global-isel=0 -fast-isel=0`. About 5 s.
- `many_graphs_agree` (ignored): 40 batches of 500 graphs; 20,000 agree in 83 s.
- `switch_on_every_width_and_case_list`: widths 1, 2, 7, 8, 9, 15, 16,
  17, 31, 32, 33, 47, 63, 64 x none, one, extremes, the sign boundary,
  dense, dense around the sign boundary, sparse, descending from the
  maximum; shuffled case order, every fifth case to the default, several
  cases per block; called with every case value and its neighbours;
  against the interpreter and `llc`.
- `a_switch_of_thousands_of_cases`: 5000 sparse `i32` cases; no
  relocation, no island.
- `far_branches_reach_across_large_functions`: a 40 KiB function (beyond
  `tbz`) and a 2+ MiB one (beyond `b.cond` and `adr`), generated in a
  loop, with a `condbr` and an `indirectbr` on a `blockaddress` crossing
  the whole function.
- `phi_cases_by_name`: a critical edge, one predecessor listed by five
  edges, a swap around a loop, a three-way rotation on a self loop,
  constants, `undef` and `poison` incoming, an `i17` `phi` switched on.
- `block_address_tables_link_and_run`: tables of `blockaddress`es in
  data (one of a block no `indirectbr` lists), passed in from C, jumped
  to directly and through a `phi`; one in a COMDAT group; static and PIC,
  with and without function and data sections; GNU ld, lld, mold.
- `the_branch_forms`, refusals by name.

## Mutations (each caught, then reverted)

1. `condbr`: `tbnz` where `tbz` belongs (the true block next) — 5 tests
   fail, the random graphs with 24 disagreements.
2. `switch`: the binary search's `b.hi` as a signed `b.gt` — the width
   test (183 disagreements) and the random graphs. Dropping the zero
   extension — five tests, up to 8232 disagreements.
3. The `phi` protocol, in `hod_cg/src/phi.rs`: incoming values copied
   straight into the `phi`s' homes in order (a sequentialized parallel
   copy) — `phi_cases_by_name` (9) and the random graphs (81).
