# WP-057 — `hod_dwarf`: subprograms and variables

The design is `spec/dwarf.md`. The contract of what landed is §6.1
(families 0, 1, 4, 38, 39 used; 69 to 71 appended), §6.4, §6.7, §7.2,
§8.8 and §9, and `spec/codegen.md` §9.5. This file records what the work
package did, what it measured, and what it left.

## What landed

- `crates/hod_dwarf/src/func.rs` (new): `UnitPlan::add_function` and
  `seal`. One subprogram DIE per placed function with a `DISubprogram`
  (`low_pc`/`high_pc`, `frame_base`, name, linkage name, decl, type and
  flags as `llc` writes them; `specification` and `object_pointer` for
  member functions), parameters and locals with `DW_OP_fbreg` locations
  and the `DIExpression` composed onto them, lexical blocks with ranges
  from `llc`'s `LexicalScopes` rule (a range list when a block's code is
  interrupted), labels, `DW_TAG_unspecified_parameters` for variadic
  definitions, function-local types nested under their scope.
- `src/die.rs`: `UnitPlan::for_functions` (the open `of_module`), the
  writer of the function DIEs, block range lists in `.debug_rnglists`,
  `.debug_addr` entries for functions, blocks and labels;
  `debug:local-static` for a global scoped in a function.
- `src/abbrev.rs`: families 69 to 71 appended (`CODE_END` 8733 → 9279);
  `DW_AT_decl_column`.
- `src/types.rs`: `debug:local-type-scope` when a local type's scope has
  no DIE.
- `hod_cg` (the minimal record and driver changes): `VarRow` gains its
  expression, `VarPlace` its frame-base forms, labels and refusals
  (`record.rs`); the driver records `#dbg_label`s and refused records and
  rewrites slot places to frame-base offsets at the end of the function
  (`driver.rs`, `cx.rs`); `Target::frame_base_offset` (`target.rs:141`);
  a slot named by a `#dbg_declare` is a home (`policy.rs:94`); the bridge
  builds the `FunctionInput` and seals the plans (`emit/lines.rs`,
  `emit/mod.rs:640`, `:873`); the error names (`error.rs:42`).
- `hod_a64`: `frame::base_offset` (`frame.rs:167`) behind
  `Target::frame_base_offset` (`target.rs:167`).
- Tests: `crates/hod_a64/tests/dies.rs`, `dies_debugger.rs`,
  `dies_throughput.rs`, `dies_support/mod.rs`, `data/dies/`;
  `lines.rs` (its inlined case moved to `data/lines/hand_inlined.ll`,
  since a function with an inlined location is now refused under full
  debug information); `hod_dwarf/tests/type_graph.rs` (the local-type
  refusal's new name).

## Evidence

- Trees equal to `llc`'s (19 and 22, `-O0 -global-isel=0 -fast-isel=0`),
  both objects `--verify` clean, in `llc`'s order: 20 objects, 664 DIEs,
  96 subprograms, 324 variables (`vars.c`, `members.cpp` by clang 19,
  clang 22 and kiln++; `hand.ll`).
- Debuggers: gdb and lldb sessions on hod's programs equal to those on
  `llc`'s, for 3 cases × LLVM 19 and 22 × GNU ld, lld and mold: recursion,
  shadowing, by-value structs (register, stack, memory), `float`/`double`,
  variadic, `this`, COMDAT functions, labels, a two-range block.
- Corpus: 14 `-g` modules; 2 DWARF 4 (not compared); 8 equal to `llc`
  (204 DIEs, 36 subprograms); refused 2 `a64:vector-element`, 2
  `debug:die-unsupported` (a global with a non-empty expression, WP-059).
- Throughput (release): 160 to 190 ns per DIE; from N to 2N the cost per
  DIE changes by 1.00 to 1.07 for 20,000 locals, a 20,000-deep scope
  chain and 2,000 functions.
- Size: `.debug_info` 1.00 to 1.05 × `llc`'s on the compared sources
  (§7.2). `stl.cpp` is refused (§7.2), so not measured.
- Mutations caught: no variadic `unspecified_parameters`; frame offsets
  8 bytes off; label-only blocks written.

## Decisions

- **One writer, not per-chunk runs** (open question 8): the plan is
  filled in module order as functions are placed; the unit writer writes
  all DIEs. Simple, deterministic, linear; per-chunk runs can come later
  behind `add_function`.
- **Locations compared by behaviour.** hod's frame is not `llc`'s, so
  offsets differ; the trees mask them and the debugger sessions decide.
- **Refuse rather than approximate**: every shape not written exactly
  has a `debug:*` name (§6.4), including every `#dbg_value`.

## Left for later

- Inlined subroutines (`debug:inlined-subroutine`), on-demand member
  declarations for member templates (`debug:specification`), local
  statics (`debug:local-static`), local types reached before their
  function (`debug:local-type-scope`), `#dbg_value` (`debug:dbg-value`).
- Out-of-line definitions outside a class, templates: WP-059.
- `LineTablesOnly`: WP-061 (§9 lists what it needs).
- `classify`'s `debug:*` refusals stay; §9 lists what must land first.
