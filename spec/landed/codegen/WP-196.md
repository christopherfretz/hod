# WP-196: system registers of real projects on AArch64; a `callbr` result only a `phi` takes

## System registers (`spec/asm.md` §5.4, §12)

Nothing new to build: WP-188 (`crates/hod_asm/src/a64/sysreg.rs`)
already accepts every name this package lists, in any case, generated
from and tested against `llvm-mc-22`. The eight `asm:operand/sysreg`
modules the real-project lane saved were built by a hod from before
WP-188 reached `main`.

Evidence on the saved modules (two abseil, three protobuf; the others
of the eight are the same functions in other flavours):
- each compiles with `hod --strict -O0 -relocation-model=pic` (exit 0,
  no refusal left);
- the template's word in hod's `.text` equals `llc -O0
  -global-isel=0 -fast-isel=0` 22's but for the general register
  (`d53be009` against `d53be008`, `mrs x9/x8, cntfrq_el0`;
  `d5380009`/`d5380008` for `midr_el1`). The rest of each function is
  hod's own code (frame, slots, register choice) and is not
  byte-identical, as for every function hod compiles.
- `crates/hod_a64/tests/sysreg_asm.rs`
  `kiln_shapes_compile_with_llc_s_words`: kiln's shapes (`optnone`,
  kiln's `target-features`, `sideeffect` `cntvct_el0`/`cntfrq_el0`,
  upper-case `MIDR_EL1` without `sideeffect`) compile, and the
  system-register words equal `llc` 19's and 22's. The runnable check
  (`cntvct_el0` read twice and monotonic, `midr_el1` equal to the C
  compiler's own `mrs`, by hod and by `llc`, every linker) is WP-188's
  `seeds_run_as_llc_builds_them`.

Still refused by name (`asm:operand/sysreg`): names outside the table
(feature-gated ones such as `id_aa64zfr0_el1`, `tpidr2_el0`, `dit`,
`ssbs`: their generic form is accepted), `msr` to a read-only register,
`msr` of an immediate to a PSTATE field (`daifset`, `spsel`, ...).

## `callbr` result only a `phi` takes (`spec/asm.md` §12)

`crates/hod_a64/src/inline_asm.rs`: on each indirect edge the result is
defined again (WP-112); a register result whose only use was the
fallthrough's `phi` stayed in its register on an edge to a block that
does not take it, and the block ended with an internal error. The edge
now releases the result after its `phi` copies.
`crates/hod_a64/tests/callbr_phi.rs`: `a_result_only_a_phi_takes` is no
longer ignored, and `loop_reg` joins the functions built by hod (plain,
stressed) and `llc` 19 and 22, linked and run.
