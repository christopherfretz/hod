# WP-121: libc++ x86-64 baseline (L0)

- `scripts/libcxx-x64-kiln.sh`: a `--compiler` for kiln's
  `cargo xtask libcxx`. It runs the suite for `x86_64-unknown-linux-gnu`
  under `qemu-x86_64` without changing kiln (`spec/harness.md` "libc++ on
  x86-64 under qemu").
- The x86-64 libc++ is Debian's amd64 `libc++-22-dev` set, the AArch64
  tree's version, under `.build/libcxx-x64/`. The static-only lib
  directory is required: kiln++ accepts neither `-static-libstdc++` nor
  `-nostdlib++`.
- Result: `docs/status/libcxx-baseline-x64.md`. 8,608 pass of 9,247
  (8,609 with the correct `target=` feature, as on AArch64). Two
  differences from AArch64: one emulation (`copy_file_procfs`) and one
  the harness's host-derived `target=` feature (`setfill_wchar_max`). No
  kiln x86-64 lowering bug was found. The emulated run is 3.7x the
  AArch64 wall time.
- Open: the kiln-side request (`KILN_LIBCXX_TARGET`, `KILN_LIBCXX_EXEC`).
  The patch is at `.build/libcxx-x64/kiln-request/` in the workspace.
