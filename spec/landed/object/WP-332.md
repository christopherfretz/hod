# WP-332: the relocation model in a `.mason.meta` unit of hod's own

Spec: `spec/codegen.md` §9.7.5. Requested by the mortar linker project
(github.com/christopherfretz/mortar, `spec/odr.md` §11 item H-3, read at
`afbdb15`; layout in its `spec/meta.md` MT-10, MT-11, MT-12, MT-26): a
`-shared` link refuses non-PIC code that binds the library's own
exported data, and hod's row makes that refusal exact for hod objects.

## The rule

- Every object (x86-64, AArch64, i386) gets one 88-byte unit, producer
  2, with one kind-1 row `reloc-model` = `static`, `pie` or `pic`, in
  `.mason.meta` (`SHT_PROGBITS`, flags exactly `SHF_EXCLUDE`, align 8, no
  group, no relocation section). With kiln's container in the module the
  unit follows kiln's bytes in the same section; kiln's bytes are
  unchanged. A container whose size is not a multiple of 8, or that has
  a relocation section, or that is a COMDAT group member (mortar drops
  such a container whole) is left untouched, and hod's unit goes into a
  second `.mason.meta` section of its own.
- The value comes from `hod_cg::model_used` (`crates/hod_cg/src/access.rs`),
  which the TLS model choice and the local-alias choice of §7.4 now read
  too, so the row cannot disagree with the code.
- The bytes: `crates/hod_cg/src/emit/mason.rs`; the section:
  `ModuleEmitter::mason_unit` (`crates/hod_cg/src/emit/mod.rs`).

## Harnesses that leave the unit out (by §9.7.5's rule)

`hod_testutil::mason::hods_unit_start` finds the unit; it is used by
`crates/hod_cg/tests/elfview/mod.rs` (every `hod_cg` comparison with
`llc`: `emit_llc`, `sym_access`, `emit_link`, ...) and
`crates/hod/tests/i386_module_asm.rs`. `crates/hod/tests/exclude.rs`
checks kiln's bytes and then hod's unit after them.

## Tests

- `crates/hod_cg/src/emit/mason.rs`: the exact bytes for each value.
- `crates/hod/tests/mason_reloc.rs`: per target and model, one
  container, one hod unit with the row, header fields; with kiln's unit
  both parse in order and kiln's bytes are unchanged; a container of odd
  size, one with a relocation and one in a COMDAT group are each left
  alone, hod's unit in a second section; deterministic; on
  x86-64 and AArch64 a program linked by every linker present (bfd, lld,
  mold, mortar, wild) runs and has no `.mason.meta`.
- `crates/hod_testutil/src/mason.rs`: the finder.

## Example

```
hod -O0 -filetype=obj -mtriple=x86_64-unknown-linux-gnu -relocation-model=pic crates/hod_cg/tests/data/exclude/mason_meta.ll -o m.o
readelf -x .mason.meta m.o
```

prints kiln's 16 bytes, then hod's unit (`MASN`, size 0x58, producer 2,
`reloc-model` `pic`).
