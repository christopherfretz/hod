# WP-111 — debug follow-ups after WP-097 and WP-098

The contract is `spec/dwarf.md` §6.17 (with §1.2, §5.7, §6.4
"Retained variables", §6.11 and `spec/codegen.md` §9.5). This file
records what the work package did, what it measured and what it left.

## What landed

- **A unit without code** (`crates/hod_cg/src/emit/lines.rs`,
  `lists_entities`): written when it lists globals, enumerations,
  retained types or imports not scoped in a function, as `llc`'s
  `DwarfDebug::beginModule` does. `dies_label::unit_with_only_imports_matches_llc`
  is no longer ignored.
- **A `#dbg_declare` of a `phi`** (`crates/hod_cg/src/driver.rs`,
  `declares_a_phi`): no row, as `llc -O0` writes none.
- **Retained variables** (`crates/hod_dwarf/src/func.rs`
  `retained_vars`, `var_location`, `exprloc_if`; `inline.rs`
  `record_retained`): a `retainedNodes` variable without a row gets a
  DIE without a location, in `llc`'s order, its type made last.
  `dies_label::ramp_frame_variables_match_llc` is no longer ignored.
- **`debug:variable-twice`**: clang 22's ramp's second declaration was
  the `phi`'s; nothing is left of it in the corpus or the `-g` set.
- **Imports** of every shape: already as `llc` writes them; a test.
- **Line classes** (`xtask/src/debug/permitted.rs`, mirrored in
  `scripts/debug-measure.py`): only the pair's file and blocks with a
  predecessor count, and `post-indexed-load` is a class (§5.7).
- `docs/status/debug.md` regenerated.

## Evidence

- Trees against `llc` 19 and 22 (`-O0 -global-isel=0 -fast-isel=0`),
  `crates/hod_a64/tests/dies_followups.rs`:
  - `units_without_code_match_llc`: 8 comparisons (imports only;
    retained types with each list dropped in turn; a unit with none,
    which neither writes; a global without a definition), 2 468 DIEs
    equal;
  - `imports_of_every_shape_match_llc`: 3 trees, 786 imports equal;
  - `declaration_of_a_phi_matches_llc`, `coroutine_ramps_match_llc`:
    3 trees each (clang 19 by `llc` 19 and 22, clang 22 by `llc` 22).
- A header-only unit (`<cstdlib>`, `<cmath>`, `<vector>`, `using
  namespace std;`): 800 DIEs, equal on 19 and 22; hod wrote nothing
  before.
- `llvm-dwarfdump --verify` (22 and 19): clean on every object of the
  tests and of the measurement below.
- gdb 16.3 and lldb 19 on the clang 19 and 22 coroutine ramp (`break
  evens`, `info args`/`info locals`, `p n`, `p __promise`, `p
  __coro_frame`), under bfd, lld and mold: 12 pairs of transcripts, each
  hod's equal to `llc`'s. Before, hod declined the module
  (`debug:variable-twice`).
- The `-g` modules (corpus 14, `-g` set 198), hod at the work package's
  base (`73865eb`) and after, release builds: `.text` byte-identical in
  all 208 modules both build; 8 objects differ, all in `.debug_info`.
  Against `llc`'s tree (normalized dump, differing lines before → after):
  - libc++'s `dangling_borrowed_subrange.compile.pass` and
    `forward_iterator.compile.pass` (clang 19, 22: 4 modules, units
    without code): 3 693 and 4 055 → 0 (797 and 875 DIEs, none before);
  - `coroutine.handle.prom/promise.pass` (clang 19, 22): 5 → 0;
  - kiln++'s `promise.pass` 7 → 2, `libstdcxx-generator-int-run` 77 → 2:
    the 2 left are one `DW_TAG_pointer_type` too many, from `hod_ll`
    keeping two equal uniqued nodes apart (below).
- Line tables: `(function, file, line)` pairs unchanged by the code
  (194 681 same both before and after); unclassified 4 → 0 with the
  class, `post-indexed-load` 4 (`xtask/tests/debug_post_index.rs`).
- Mutations, each caught and reverted:
  - the `phi` drop removed: `dies_followups::declaration_of_a_phi_matches_llc`,
    `coroutine_ramps_match_llc`;
  - `retained_vars` not called: `coroutine_ramps_match_llc`,
    `dies_label::ramp_frame_variables_match_llc`;
  - `record_retained` not called (types in another order): the same two;
  - the retained-types condition of `lists_entities` inverted, and the
    enumerations condition removed: `units_without_code_match_llc`;
  - the predecessor check, the file check, and the load check of
    `post-indexed-load` each removed:
    `permitted::tests::post_indexed_loads_by_file_and_predecessor`.

## Left

- Two `#dbg_declare` cases `llc` tells apart by position, which
  `hod_ir`'s declarations do not have: a value from another block
  (`llc` drops it) and a slot plus a constant offset, on which hod's
  code generator stops with an internal error ("a home value without a
  home", `crates/hod_cg/src/policy.rs` `finish`). No front end emits
  either at `-O0`; ignored tests in `dies_followups.rs`.
- kiln++'s coroutine ramp: `hod_ll` keeps two equal uniqued
  `DIDerivedType`s apart (`!17`, `!142`), so hod writes one pointer type
  more than `llc` (`dies_followups::kiln_coroutine_ramp_matches_llc`,
  ignored; it predates this work package).
- `DW_AT_GNU_pubnames` and the name index of split units, and
  `DW_AT_ranges` on a coroutine's subprogram: not done, §6.17 says why.
