# WP-124 — x86-64 control flow (X-control; design 0006 §5, §10)

Landed: `crates/hod_x64/src/control.rs`, `crates/hod_x64/tests/control.rs`
with `tests/common/control_gen.rs`, `spec/codegen.md` §5.6.3, the
support-matrix rows below.

## What is implemented

- `condbr` on a materialised `i1`: `test r8, 1` + `jne`/`je`, the branch
  to the next block omitted; constant conditions and equal targets are a
  `br`.
- `condbr` on a deferred integer `icmp` of class `Gpr` (every predicate,
  every width, pointers): `control::fused_icmp`, operands first, then
  `cmp`/`test`, then the `jcc` with nothing in between. Odd widths are
  shifted to the top of 32 or 64 bits; 8 and 16 bits compare at their
  own size. **Not reachable on this branch**: `int::icmp` (WP-122) still
  refuses every `icmp`, so nothing is deferred; the fused tests skip
  while `icmp` is refused as `x64:todo:int` and run once WP-122 lands.
  They were run on the branch with a temporary deferral in `int::icmp`
  (`if cx.may_defer(inst) { return cx.defer(inst) }`), not committed.
- `switch` of class `Gpr` through `hod_cg::switch` (canonical cases,
  constant target, search step, case mask, `LINEAR_CASES`); of class
  `Mem` (`i65` and wider) limb by limb in IR order, as `hod_a64`'s
  `tail::switch_wide`.
- `indirectbr` (`jmp r`; a direct `jmp` on a `blockaddress` constant),
  `blockaddress` in code (`control::block_address`: `lea r, [rip +
  label]`, a `rel32` fixup), and through the glue: `common.rs:531` now
  routes `Const::BlockAddr` to it (the one line that refused as
  `x64:todo:control`). `blockaddress` in data and the shared `ud2` trap
  of unreachable blocks are the core's (§6.1, §9.6), checked on x86-64.

## Refusals

- `x64:blockaddress`: a `blockaddress` of another function's block used
  in code (`a64:blockaddress` on AArch64; `classify` rejects it first).
- `x64:todo:condbr-fcmp`: a `condbr` on a deferred `fcmp` (WP-127
  replaces it with one call of its flags-setting compare).
- `x64:todo:control` is no longer used (kept, as AArch64 keeps its old
  names).

## Evidence

`hod_interp` is the oracle, `llc -O0 -fast-isel=0` 19 and 22 (PIC) the
second; hod in plain and `Stress::ALL` modes; one object and one
emulated process per mode.

- Random graphs (WP-037's generator, copied: the AArch64 file imports
  `hod_a64`): 2000 graphs with `undef`/`poison` incoming values against
  the interpreter, 1000 against both `llc`s too, 1000 with `phi`s of
  `blockaddress` feeding `indirectbr`; 6 calls each.
- Switches: 14 widths (1, 2, 7, 8, 9, 15, 16, 17, 31, 32, 33, 47, 63, 64)
  × 14 case lists (empty, one, dense, sparse, negative, extremes, the
  immediate boundaries `0x7f`..`0x8000_0000_0000_0000`, runs of 4, 5,
  9, 10, 19 cases around the search's boundaries), every case value and
  its neighbours; corner cases (all to the default, constant, 64-bit
  values beyond `simm32`); 5000 sparse cases (17 ms to compile, no
  relocation); `i65`, `i100`, `i128` from a C driver with junk above the
  width.
- Fused compares (with the temporary deferral): 1630 functions (10
  predicates × `i1`, `i7`, `i8`, `i16`, `i17`, `i32`, `i33`, `i63`,
  `i64`, `ptr` × register/register, an operand twice, every immediate
  boundary on the right, some on the left × both layouts), 10810 calls,
  junk above every width, `phi`s with a constant 0 incoming on both
  successors: all agree. The disassembly (`llvm-objdump`) of every
  fused pair and switch has the `jcc` right after its `cmp`/`test`
  (or another `jcc`); every `jcc` of a random batch satisfies the flags
  rule.
- `blockaddress` tables in data (one of an unreachable block, which is
  `ud2`), through `phi`s, in a COMDAT, formed in code and returned (of
  an unreachable block: `ud2` too), with and without function sections,
  linked by GNU ld, lld and mold as PIE and run.
- Mutations, each caught then reverted: an `xor r11d, r11d` between the
  fused `cmp` and its `jcc` (fused agreement and the flags-rule test);
  no shift for an odd width below 32 (fused agreement); `jg` instead of
  `ja` in the switch search (switch tests); `test r8, 0xff` instead of
  bit 0 (random graphs).
- Text: a random batch of 600 graphs is 158570 bytes against `llc` 22's
  114163 (hod/llc 1.39; the prologue saves five registers, branches are
  `rel32` forward).

## Where hod differs from `llc`

- No jump tables (§6.2); `llc` builds one for dense switches.
- Forward branches are always `rel32` (no relaxation).
- An odd-width compare shifts both operands left instead of masking or
  sign-extending them.
- A `switch` of `i65`..`i128` is a linear chain of limb compares.

## Seeds

None of the 50 `tests/ir` seeds builds on x86-64 yet (48 declined as
`global:variable-definition`, WP-123). The control rule of design 0006
§8 risk 7 (the first of duplicate switch cases) has no seed: duplicate
case values are invalid IR that `hod_ll` and LLVM reject.

## Support matrix

x86-64 switched on: `inst:condbr`, `inst:switch` (`Int`, `I128`,
`IntWide`), `inst:indirectbr`, `operand:blockaddress`,
`init:blockaddress`.
