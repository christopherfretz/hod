# Real projects through kiln and hod

Generated by `scripts/oss/oss-report.py status` from the lane's reports (docs/VALIDATION.md "Real projects (L9)"): each project built through its own build system with kiln at `-O0` (flavour `O0`) and `-O0 -g` (`O0g`), three ways: `llc` (kiln's LLVM back end, the control), `hod` (kiln with hod, falling back to llc where hod declines), `strict` (no fallback). `TUs`: the translation units of the build step (the compile wrapper's log). `objects`: the object jobs (`-c`) in kiln's statistics log of the hybrid build, which covers the build and the test steps, so it counts a TU compiled for several targets once per target and the compiles a project's tests run (compile-failure tests, package tests); `no backend` among them: jobs kiln's front end rejected before any back end ran (a compile-failure test's expected rejection), counted in no later column. Compile-and-link jobs (`kiln++ x.cc -o prog`) are not objects and are not counted. `built by hod`: objects whose `backend` is `hod`; `fell back`: offered to hod and declined or failed; `not offered`: kiln took the LLVM route itself (an `opt` trigger). Tests: passed/total (ctest). `revision`: the project's tag or commit; `hod`: the hod commit of the hod and strict builds; `kiln`: the kiln commit of the row's builds (the control's included); `at the candidate`: whether the strict build (without one, the hod build) used the candidate's hod, `a68a0d5d` (a control does not depend on hod).
