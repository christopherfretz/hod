# WP-049 — unwind tables in `emit_module`

Landed: `spec/codegen.md` §9.1 (the record's unwind fields), §9.3 (the
shared row type, the shared trap's rows), §9.4 (`nounwind` rows), §9.7
(the tables, two refusals); `spec/eh.md` §1.1 (filling `Fde`, the FDE
rule), §9.3 (`llc`'s rule for calls of `nounwind` functions, one wording
for `landing`), §9.10; the AArch64 rows `module:uwtable`,
`function:may-unwind` and `attr:uwtable`.

## What it did

- One row type: `hod_cg::{CfiOp, CfiRow, ClauseRow}` are re-exports of
  `hod_eh::{Op, Row, Clause}`. `hod_cg` depends on `hod_eh`; the rows go
  to `write_eh_frame` as they are.
- `FuncRecord` gained `personality`, `nounwind`, `uwtable` (set by
  `compile_function` from the module) and `needs_unwind_entry()`, LLVM's
  `needsUnwindTableEntry`. `CallSiteRow` gained `nounwind`: a direct call
  of a function declared `nounwind` (`callToNoUnwindFunction`); calls a
  target records itself (`FnCx::record_call_site`) are not. No signature
  a target calls changed.
- `emit_module` (`src/emit/unwind.rs`) writes the LSDAs (one
  `write_lsdas` call, rows without a pad whose call cannot unwind left
  out) and then `.eh_frame` (one `write_eh_frame` call), each FDE at the
  function's section symbol plus its offset after the merge, the
  personality slot from `personality_ref`. The LSDA rows are mapped into
  three buffers reserved from the row counts; nothing is allocated per
  function.
- The shared trap after the exit sequences restates the body's CFA rule
  and saved registers (it is reached from the body).
- Refused by name: `module:linker-option-not-a-pair`,
  `eh:unknown-personality-without-pads` (`llc` writes an LSDA of call
  sites hod does not record).
- Declarations are named in the object before the tables are written
  (`hod_eh` reads the personality's and type-information names).

## Tests

- `hod_cg/tests/emit_eh.rs`: modules with `nounwind`, `uwtable`,
  `uwtable(sync)`, internal functions, a personality without pads,
  catches, a catch-all, filter and cleanup, calls of `nounwind` functions
  inside and between `invoke` ranges, two pads, a COMDAT function with
  pads; each compiled by `llc` 19 and 22, with and without
  `-function-sections`; hod's chunk carries `llc`'s code and rows read
  back from `llc`'s tables. The objects agree in sections, groups,
  symbols, relocations and bytes (44 FDEs, 16 LSDAs), except `llc`'s
  unreferenced `GCC_except_table<n>` labels. Planted wiring bugs in the
  rows (a shifted offset, a dropped COMDAT FDE, exchanged LSDA rows) fail
  the comparison. The COMDAT function with an FDE and an LSDA defined in
  two hod objects links with GNU ld, lld and mold (`--fatal-warnings`),
  runs (an exception thrown through it is caught in it), and
  `readelf --debug-dump=frames` and `llvm-dwarfdump --eh-frame` read the
  program's tables without a complaint. Also: the `nounwind` rows of the
  core and their absence from the LSDA; both refusals; the shared trap's
  rows.
- `hod_cg/tests/emit_merge.rs`: synthetic pads, personalities and
  attributes on 1098 generated functions; the tables decoded from the
  object (1092 FDEs, 861 LSDAs) are each function's, at its place after
  the merge, for any chunking (shuffled chunk boundaries) and thread
  count, static, PIC and `function_sections`.
- The WP-044 differential (`policy_diff`, `common/exec.rs`): the
  unwinder and the personality now read only the `.eh_frame` and LSDAs
  `emit_module` wrote; each frame unwound through must have an FDE whose
  CFA rule at the call is `FP+16`. 4380 FDEs and 1540 LSDAs read, 1130
  exceptions thrown, 1290 landing pads entered, all equal to the
  interpreter.
- `hod_a64/tests/unwind.rs`: `uwtable` leaf functions with body slots
  of 0, 16, 4112 bytes and 1 MiB, compiled by hod near and in far-branch
  mode, linked by GNU ld, lld and mold, trap; `_Unwind_Backtrace` from
  the `SIGTRAP` handler and `gdb`'s `backtrace` both walk leaf, `outer`,
  `main` (24 walks each). Without the FDEs both fail. The throw through
  a hod frame that calls an external function is written and ignored
  until calls land (WP-038).

## Planted mutations (in `src/emit/unwind.rs`, reverted)

| mutation | caught by |
|---|---|
| FDE start one word after the function | `emit_eh` (comparison, COMDAT link), `emit_merge` ("0 FDEs at its place") |
| no FDE for a COMDAT function | `emit_eh` (comparison, COMDAT link) |
| LSDAs of neighbouring functions exchanged | `emit_eh`, `emit_merge` (landing pad), `policy_diff` (std::terminate) |

## Cost

`throughput::unwind_table_cost_per_function` (release): a generated
module of 4000 functions (4000 FDEs, 1035 LSDAs): `emit_module` 487 ns
per function with the tables, 357 without, so 130 ns per function for
both tables; `.eh_frame` 120,600 bytes, `.gcc_except_table` 53,588.
