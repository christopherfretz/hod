## Why the line findings are not in `tests/debug`

An unclassified `(function, line)` pair fails `cargo xtask debug run`
whatever the test's `xfail` says (`spec/harness.md` "debug", "Lines").
An xfail test there would fail the gate; an ignored test states the
requirement without doing so.

## Repeating it

Build the release `hod`, then the commands of each section of
`docs/status/debug.md`. Corpus-wide runs at `-j 4` at most, one at a time.
The libc++ and kiln paths of `scripts/debug-gset.sh` default to the
workspace's `.toolchain/` and `kiln/`; the selection is fixed by rule,
the result depends on the system's libstdc++.
